# Player Notepad

Right-click a player and choose **Add to notepad** to put their name in a notepad in the
RuneLite sidebar. The notepad is plain text: you can type your own notes next to names,
and the **Clear** button empties it (after asking first).

- Works on players in the game world, and on names in chat, private messages, and the
  friends, ignore, clan and chat-channel lists. Each can be turned off in the config.
- Names already on their own line are skipped (configurable).
- The notepad is saved with your RuneLite config, so it survives restarts.

## Running

```
../run-dev.sh player-notepad-plugin
```
